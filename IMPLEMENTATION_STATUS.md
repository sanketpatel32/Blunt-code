# Implementation status

## Completed

- Milestone 0: Go service, SQLite migrations, health/meta APIs, loopback-only HTTP server, Vite-to-embedded-assets build script.
- Milestone 1: persistent workspaces and rules, validated roots, native Windows picker, safe source discovery, language detection, default exclusions, lazy tree API.
- Milestone 2: analyzer registry integration, Quick/Standard/Deep scan profiles (Quick runs Ruff/Biome only; Deep matches Standard in V1), persisted file and directory selection overrides (including more-specific file exceptions), direct-process analyzer runs, scan lifecycle/cancellation, SSE events, normalized-result persistence, partial-failure outcomes, and local Markdown reports.
- Milestones 3–5: Ruff and Biome structured parsers, pinned checksum-verified private installation, tool readiness/install APIs, normalized report rendering/export, and coverage-aware new/fixed/persistent comparison.
- Milestone 6 implementation: Semgrep 1.172.0's Windows wheel and official uv 0.11.16 are checksum-verified before private app-data installation; bundled local rules are extracted and versioned there; scan plans use only those rules with metrics, version checks, inherited app token, and user settings disabled.
- Milestone 7 implementation: managed SonarQube Community Build, SonarScanner, and Java 21 artifacts are pinned and checksum-verified, safely extracted under app data, configured on a dynamically selected loopback port, and bootstrapped with DPAPI-protected local credentials. The adapter starts and stops this private server for scans; a Windows fixture scan completed with Ruff, Semgrep, and SonarQube all succeeding.
- Milestone 8 implementation: path/origin guards, archive traversal protection, crash recovery, process cancellation and Ctrl+C lifecycle shutdown, bounded per-tool process output and timeouts, redacted local diagnostic logs with a 500 MB cap, Windows per-data-directory single-instance protection, persisted offline mode (enforced by tool installation), local-only `bluntcode doctor` diagnostics (including disk-space and JSON output), documentation, notices, checksum-verified local/HTTPS installer paths, build scripts, and focused unit/integration tests.
- Milestone 9 implementation (25 improvement loops, release 0.2.0): headless `bluntcode scan <path>` CLI for automation and CI (`--profile quick|standard|deep`, `--json`, `--timeout`, `--quiet`; stderr progress, stdout summary, exit codes 0 completed incl. warnings / 1 failed-cancelled-timed out / 2 usage / 130 Ctrl+C); API additions — global recent-scans feed with dashboard summary aggregates (`GET /api/v1/scans`), SARIF 2.1.0 export (`report.sarif`, VS Code / GitHub code scanning compatible), standalone self-contained HTML report (`report.html`), CSV findings export with UTF-8 BOM via a filter pipeline shared with the JSON findings endpoint (`findings.csv`), coverage-aware fixed-findings listing against the previous completed scan (`/fixed`), and an enum-only loopback open-folder endpoint launching Explorer for the data/reports/logs/tools directories (`POST /api/v1/system/open-folder`); deep profile now genuinely deeper (Ruff runs with `--select=E,W,F,B,SIM,C4,RET,ARG,PLR`; quick/standard byte-identical; diagnostic logs record the analyzer command line); web UI reworked — App.tsx monolith split into pages/components/hooks/lib modules with the test suite grown from 16 to 124 cases, dark mode with OS-preference sync and no-flash bootstrap, home dashboard with activity summary and recent scans, report severity distribution and per-analyzer mini-bars with print styles, sortable findings columns, debounced text filters with removable chips and severity pill filters, "What changed" fixed-findings panel, export menu (Markdown/HTML/SARIF/CSV with CSV honoring filters), scan history severity mini-bars and profile badges, stacked toast notifications replacing the single notice banner, layout-aware loading skeletons and tool install/repair/update busy feedback, global keyboard shortcuts (`g`+`h/w/t/s`, `n`, `/`, `?` help dialog), recursive file tree search with highlighting and retryable loads, dialog focus traps/aria-modal/backdrop close, error boundary with recovery, real 404 page, About page, skip-to-content, relative timestamps with absolute tooltips, clipboard copy actions, arrow-key row navigation, Settings buttons opening data folders in Explorer, friendly empty states, and an all-clear celebration for zero-finding scans.
- Milestone 10 implementation (20 feature loops plus a QA hardening batch, release 0.3.0): CI severity gates on headless scans (`--fail-on` with `high+` shorthand, `--max-findings`, exit 1 on a tripped gate) and baseline diff mode (`--baseline` accepts a previous scan ID or a Blunt Code SARIF file via new `partialFingerprints` round-trip, so gates count only new findings); expanded bundled semgrep rulepack (2 → 20 Python/JS-TS security rules, rules version 2.0.0, exercised by a live semgrep 1.172.0 scan — 0 findings on a clean fixture); configurable SonarQube startup wait (`BLUNTCODE_SONAR_STARTUP_TIMEOUT`, immediate health polling, progress logging); per-project `.bluntcodeignore` honored by CLI, UI, and file tree; versioned JSON report export (`--format json` and a `findings.json` API download, byte-stable output); Biome React auto-domain (plan-time React detection, injected `linter.domains.react` config for the pinned Biome 2.5.6); fingerprint-based finding suppression (workspace-scoped API routes plus full web UI: suppress with reason, restore, Suppressions panel, suppressed status excluded from counts, reports, and gates); severity trends (`GET /api/v1/workspaces/{id}/trends` and a dependency-free SVG stacked-bar chart on the workspace page); bounded analyzer parallelism (`--jobs` semaphore, default still sequential); watch mode (`--watch` with debounce and coalescing rescans); built-in committed-secrets detector and TODO/FIXME comment tracker (in-process, no downloads);
