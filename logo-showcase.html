Blunt Code — logo variants

Local code analysis for Windows. Concept: blunt = direct, decisive, shield. Security + code quality. 6 variants, distinct pattern families, all work at 16px favicon → 512px store.

V1 — Shield Chevron security

Shield = protection, Windows security. Chevron check = passed analysis. Dot = live scan. Most explicit for pentest/hacking suite. Works as app icon (shield silhouette).

V2 — Blunt Chisel literal

Literal blunt edge: chisel tip = blunt, not sharp. Direct, decisive tool. Diagonal cut creates dynamic B shape. Memorable, owns the name.

V3 — Brackets Check code quality

Code brackets { } + check = lint passed. Most devtool-native. Instant "code analysis" read at 16px. Balanced, not aggressive.

V4 — B Monogram brand

Letter B = Blunt. Two bowls = blunt double-edge. Strongest brand recall, works as favicon letter. Most minimal, timeless.

V5 — Analysis Flow graph

Three nodes + path = scan pipeline: files → analysis → report. Mirrors DependencyGraph in app. Best for data-story (trends, findings).

V6 — Blunt Line editorial

Blunt = flat end, not pointed. Three lines = code lines, bottom faint = blunt. Most minimal editorial, Hallmark-friendly.

Recommendation: V1 Shield Chevron — only one that signals security + Windows + pentest (your 22 hacking tests) at a glance, shield silhouette owns app icon, check gives positive "all clear" vibe, dot = live. As fallback keep V3 Brackets for devtool pages and V4 B for 16px favicon. All use same palette: #0F172A ink + #3B82F6 accent oklch(56% 0.22 268) + white — matches tokens var(--color-brand-mark/accent).
