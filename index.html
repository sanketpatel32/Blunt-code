Install in 30 seconds

One line, no admin. Installs to %LOCALAPPDATA%\Programs\BluntCode, verifies SHA-256, creates a Start Menu shortcut, and launches the app. Rerunning either command upgrades in place.

PowerShell — Win+R → powershell
irm https://github.com/sanketpatel32/Blunt-code/releases/latest/download/install-latest.ps1 | iex
Cmd — Win+R → cmd
curl -fsSL -o "%TEMP%\install-bluntcode.cmd" https://github.com/sanketpatel32/Blunt-code/releases/latest/download/install.cmd && "%TEMP%\install-bluntcode.cmd"

Prefer a portable build? Grab the ZIP + SHA-256 from Releases and run bluntcode.exe.

Why Blunt Code

Four linters means four installs and four PATH fights — and findings scattered across terminals. Blunt Code is one app, one report.

One bluntcode.exe — tools sandboxed under %LOCALAPPDATA%\BluntCode\tools, never touching global PATH
Findings scattered across terminals
One report — Markdown / HTML / SARIF / CSV / JSON, filterable by tool · rule · severity · path
Cloud gates that ship your source
Loopback only — 127.0.0.1, SQLite + reports stay on disk, offline mode after first download
"Fix later" that never sticks
Suppressions that ship with the repo — bluntcode:ignore at the source, fingerprint suppressions, .bluntcodeignore

01Private by design

Loopback server, zero telemetry, SQLite at %LOCALAPPDATA%\BluntCode\bluntcode.db. Your code never leaves the machine.

02One report, every tool

Severity, rule, analyzer, path, status — filter without leaving the report. Export to Markdown, HTML, SARIF, CSV or JSON.

03History & comparisons

Every scan is kept. New, fixed and persistent findings are diffed automatically so regressions stand out.

04Suppressions that stick

Fingerprint-based, reason-tagged, restorable — and exportable so the whole team shares one source of truth.

05CLI + GUI, same engine

bluntcode scan for scripts and CI gates; the app for exploring. One data dir, one truth.

06Incremental scans

Unchanged files skip re-analysis, so the second scan of a workspace is seconds, not minutes.
