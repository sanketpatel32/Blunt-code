# Blunt Code — llm.txt for AI agents

> Blunt Code is a local-first code quality & security analyzer for Windows. One `bluntcode.exe` runs Ruff, Biome, Gitleaks, Semgrep, SonarQube, OSV Scanner on deep scans, plus built-in secrets/TODO detectors on loopback 127.0.0.1 (no cloud, no telemetry). Use headless `bluntcode scan` for automation/CI.

- **Version:** 0.7.0 (2026-08-26) — shadcn UI (Tailwind+Radix+CVA+lucide)
- **Repo:** https://github.com/sanketpatel32/Blunt-code
- **Platform:** Windows 10/11 amd64, standard user, no admin, no global Python/Java/Node
- **License:** MIT (`LICENSE`), third-party notices (`THIRD_PARTY_NOTICES.md`)
- **Latest release ZIP:** `BluntCode-0.7.0-windows-amd64.zip` + `.sha256`

## When to use Blunt Code (agent decision tree)

- User asks to lint/scan/audit local code → `bluntcode scan <path> --json` or `--format sarif|jsonl|csv`
- User wants CI gate (fail on severity) → `bluntcode scan --fail-on high+ --max-findings 50`
- User wants baseline (ignore known debt) → `bluntcode scan --baseline <scan-id-or-sarif>`
- User wants docs without launching UI → `bluntcode agent docs` (this file) or `bluntcode llm`
- User wants health check → `bluntcode doctor --json`
- User wants config/paths → `bluntcode config --json`

## Quick start for agents (non-interactive)

```powershell
# 1) Health + paths (no lock contention if app is running? doctor --json is lock-free for read, --fix needs lock)
.\bluntcode.exe doctor --json
.\bluntcode.exe config --json

# 2) Headless scan — JSON summary (progress on stderr, JSON on stdout, quiet suppresses progress)
.\bluntcode.exe scan "C:\Projects\my-app" --json --quiet --timeout 10m

# 3) Full JSON report document (same bytes as GET /api/v1/scans/{id}/findings.json, envelope-stable)
.\bluntcode.exe scan "C:\Projects\my-app" --format json --quiet > report.json

# 4) SARIF baseline round-trip
.\bluntcode.exe scan "C:\Projects\my-app" --format sarif --quiet > baseline.sarif
.\bluntcode.exe scan "C:\Projects\my-app" --fail-on high+ --baseline baseline.sarif --json --quiet

# 5) GitHub annotations for PR checks (workflow-commands on stdout, summaries on stderr)
.\bluntcode.exe scan "C:\Projects\my-app" --format github --github-cap 10

# 6) Watch (polls every 2s, rescans after 1.5s quiet; gates never exit, Ctrl+C -> 130)
.\bluntcode.exe scan "C:\Projects\my-app" --watch --watch-poll 2s --watch-quiet 1.5s
```

**Rules for agents:**
- Always pass absolute Windows path as first positional (`C:\...`). Flags may appear before or after.
- Use `--quiet` when parsing stdout as JSON — progress goes to stderr.
- Never use `--format github` with `--watch` (usage error exit 2) or `--json` with `--format json` (conflict).
- Use `--timeout 30m` default; set explicit for CI.
- Use `--jobs N` to parallelize analyzers (default sequential). `--incremental` reuses unchanged files; `--watch` enables it from 2nd scan.

## CLI reference (agent-relevant)

```
bluntcode [path] [--no-browser] [--port N] [--version]   # launch web UI (loopback)
bluntcode help | --help | -h
bluntcode doctor [--json] [--fix]                         # diagnostics + optional self-heal
bluntcode config [--json]                                 # effective config (paths, env, tool versions)
bluntcode scan <path> [--profile quick|standard|deep] [--format text|json|github|sarif|csv|jsonl|markdown]
                    [--json] [--quiet] [--timeout 30m] [--output FILE] [--save-baseline FILE]
                    [--fail-on critical,high,...|high+] [--max-findings N]
                    [--baseline <scan-id|./file.sarif>] [--gate-analyzer a,b] [--gate-category c,d]
                    [--github-cap 1..50] [--jobs N] [--incremental] [--watch] [--watch-poll dur] [--watch-quiet dur]
bluntcode prune <path> [--keep N]                         # retention: keep newest N scans
bluntcode agent [--help] | agent docs | agent scan <path> [scan flags]  # agent helper, docs dump
bluntcode llm | llms                                      # cat this file to stdout
```

### `bluntcode scan` exit codes
- `0` completed (warnings ok) or gate passed
- `1` failed/cancelled/interrupted/timed out OR gate tripped (`fail: ...` on stderr)
- `2` usage error (bad flag/path, unreadable baseline)
- `130` Ctrl+C (graceful then forced)
- With `--baseline`, gate counts only *new* findings not in baseline. Baseline `Split` prints `baseline: X known excluded, Y new`.

### `bluntcode scan --json` schema (stable, snake_case)
```json
{
  "scan_id": "uuid", "workspace": "name", "workspace_path": "C:\\...", "profile": "standard",
  "state": "completed|completed_with_warnings|failed|cancelled|interrupted",
  "timed_out": false, "started_at": "2026-08-26T00:00:00Z", "finished_at": "...", "duration_ms": 1234,
  "total_findings": 8, "severity": {"critical":0,"high":1,"medium":2,"low":3,"info":2,"total":8},
  "comparison": {"available": true, "new": 3, "fixed": 1, "persistent": 5},
  "analyzers": [{"id":"ruff","version":"0.9...","state":"succeeded","findings":2,"duration_ms": 400,"error":""}],
  "report_markdown_path": "C:\\...\\reports\\...", "error": ""
}
```

### Other machine-readable outputs
- `--format json` -> `reports.Model` (`schema: "bluntcode/scan-report"`, versioned, findings sorted path/line/rule, BOM-free, sorted severity)
- `--format sarif` -> SARIF 2.1.0 (`partialFingerprints: bluntcode/v1` = sha256 fingerprint, round-trips via `--baseline`)
- `--format csv` -> RFC4180 + UTF-8 BOM, Excel-safe (formula cells prefixed `'`)
- `--format jsonl` -> NDJSON findings, export ordering, `derivedStatus`
- `--format github` -> `::error|warning|notice file=...,line=...,col=...::msg` (percent-encoded `,`,`:`,`%`,`\n`, capped `github-cap` per severity)
- `doctor --json` -> `doctor.Result` with checks `[{id,status,detail}]`, `ExitCode()` 0/1
- `config --json` -> fixed-key map: version, paths `{dataDir exists,db,tools,reports,logs,temp}`, `BLUNTCODE_SONAR_STARTUP_TIMEOUT`, settings, tools versions

## HTTP API (when web UI is running on 127.0.0.1)

Base: `http://127.0.0.1:<port>/api/v1` (port printed on stdout, or `--port 0` picks free)

- `GET /health`, `GET /meta` (version), `GET /workspaces`, `POST /system/select-folder`
- `GET /workspaces/{id}`, `GET /workspaces/{id}/scans?page&page_size`, `GET /workspaces/{id}/trends?limit=20`
- `GET /workspaces/{id}/risk` -> `{grade:A-D, score:float, delta:?}`
- `GET /scans/{id}`, `GET /scans/{id}/findings?severity=&status=&rule=&analyzer=&path_prefix=&q=&sort=&page=&page_size=`
- `GET /scans/{id}/report.md|.html|.sarif`, `GET /scans/{id}/findings.csv|.json|.jsonl`, `GET /scans/{id}/fixed`, `GET /scans/{id}/compare?with=`
- `GET /findings/search?q=&severity=&analyzer=&workspace_id=&page=` (global)
- `GET /workspaces/{id}/suppressions`, `POST/DELETE /workspaces/{id}/suppressions/{fingerprint}`, `GET/POST .../suppressions.csv|/import`
- `GET /stats` -> `{workspaces, scans:{total,completed,running}, findings:{critical..}, suppressions, tools:{ready,total}, risk_grades:{A..}}`
- `POST /workspaces/{id}/scans` (start), `DELETE /scans/{id}`, `DELETE /workspaces/{id}/scans?keep=N`
- `GET /update/check`, `POST /update/apply` (stages `install-latest.ps1 -WaitForCloseSeconds`)

Auth: none (loopback). Rate limit: token bucket 30/30m on mutations -> `429 RATE_LIMITED` + `Retry-After`.

## File layout & ignores

```
%LOCALAPPDATA%\BluntCode
├── bluntcode.db
├── reports\  logs\  tools\  temp\
```

- `.bluntcodeignore` at workspace root: `pattern` per line, `#` comment, LF/CRLF, `\`→`/`, cap 1000/64KiB, `!` negation skipped, merged additively with `GET /workspaces/{id}/rules` (`exclude`, case-insensitive, `dir/**`, `**/name`, basename)
- Inline ignore: `bluntcode:ignore` (or `bluntcode:ignore secrets.aws-access-key-id reason: ...`) suppresses same/next line for built-ins (`secrets`, `todo`)
- Suppression: `POST /workspaces/{id}/suppressions {"fingerprint":"64hex","reason":"..."}` (500 chars), hides from next scan, reports, gate

## Scan profiles & analyzers

- **quick:** ruff+biome
- **standard:** +gitleaks +semgrep (25-rule local pack) +sonarqube (polyglot, 10m startup, env `BLUNTCODE_SONAR_STARTUP_TIMEOUT`)
- **deep:** standard + ruff extended `E,W,F,B,SIM,C4,RET,ARG,PLR` + osv-dependencies (OSV Scanner lockfile CVE scan)
- **secrets:** AWS/GH/Slack/Google/JWT/Stripe/OpenAI/Anthropic/Azure, entropy + placeholder filtering, msg = `prefix + length` never secret
- **todo:** `TODO|FIXME|HACK|XXX|BUG` whole-word, case-sensitive, 200 chars, follower heuristics

Languages: 40+ via `internal/discovery` — Py, JS/TS, Go, Java, Kotlin, C#, C/C++, Ruby, PHP, Rust, Swift, Scala, ObjC, Vue, Svelte, CSS/SCSS/HTML/JSON/YAML/TOML/XML/SQL/GraphQL, sh/ps1/bat, MD/INI/properties/.env/Dockerfile/PEM

## Agent best practices

1. Prefer `bluntcode scan --json --quiet` for structured parsing. Write JSON to temp file if large (`--output` for doc formats).
2. For CI, combine `--fail-on`/`--max-findings` with `--baseline` to avoid debt explosion. Capture SARIF once: `--save-baseline baseline.sarif`.
3. Use `--incremental` for speed on unchanged workspaces (SHA-256 per file, invalidated on analyzer/profile/version change). Watch already incremental from 2nd scan.
4. Handle `instance.ErrAlreadyRunning` (“Only one Blunt Code process can use the data directory”) → ask user to close UI tray, or `taskkill /IM bluntcode.exe /F`, or retry `doctor`.
5. Always scrub/log `fingerprints` (64hex sha256 of rule+path+lines) for suppression/baseline, not `id`.
6. Respect `prefers-reduced-motion`, `hostileCorpus` escaping — all strings HTML/control-scrubbed.
7. Docs: `docs/ci.md` (CI), `docs/ignoring-findings.md`, `docs/configuration.md`, `docs/architecture.md`, `docs/analyzers.md` — or `bluntcode agent docs`.

## Examples for agents

```powershell
# Agent: scan and summarize top findings
.\bluntcode.exe scan "C:\repo" --json --quiet | ConvertFrom-Json | ForEach-Object { $_.severity; $_.analyzers }

# Agent: baseline-gated CI step (PowerShell)
.\bluntcode.exe scan "C:\repo" --fail-on high+ --baseline .\baseline.sarif --json --quiet; if($LASTEXITCODE -eq 1){ throw "gate failed" }

# Agent: global search via API (when server is up)
$port = (Get-Content "$env:LOCALAPPDATA\BluntCode\port.txt" -ErrorAction SilentlyContinue)
Invoke-RestMethod "http://127.0.0.1:$port/api/v1/findings/search?q=TODO&severity=low&page_size=5"

# Agent: start scan via API then poll
$ws = (Invoke-RestMethod "http://127.0.0.1:$port/api/v1/workspaces").items[0]
$scan = Invoke-RestMethod -Method Post "http://127.0.0.1:$port/api/v1/workspaces/$($ws.id)/scans" -Body '{"profile":"quick"}' -ContentType "application/json"
```

## Troubleshooting

- `Close Blunt Code before installing an update.` → `Get-Process bluntcode | Stop-Process -Force`, or run installer with `-WaitForCloseSeconds 30` then close UI.
- `timeout after 30m: cancelling scan` → increase `--timeout` or `--jobs`, or scope with `--gate-analyzer`.
- `bluntcode scan: exactly one workspace path is required` → pass absolute path first positional.
- `bluntcode scan: --json cannot be combined with --format json` → pick one: summary vs full report.
